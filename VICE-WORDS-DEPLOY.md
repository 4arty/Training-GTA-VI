# VICE WORDS — как скачать и разместить бесплатно

## 0. Что внутри и что важно знать

- **Стек:** Next.js 16 + React 19 + Tailwind CSS 4. Бэкенда-логики по сути нет:
  весь прогресс игрока хранится в **localStorage** браузера, список слов — в
  `src/lib/words.ts`. Prisma в проекте осталась от шаблона и приложением
  **не используется**.
- Это значит: любые переменные окружения для деплоя **не нужны**, а подойдёт
  любой бесплатный хостинг, умеющий Next.js (Vercel, Netlify и т.д.).
- **Требования к машине:** Node.js **20.9+** (nodejs.org, LTS-версия)
  или Bun 1.2+ (bun.sh).

## 1. Как скачать исходники

Архив `vice-words-source.zip` содержит весь код (без `node_modules` и сборки —
они ставятся одной командой).

Распаковали? Дальше два сценария:

**Запустить у себя локально:**
```bash
cd vice-words
npm install        # или: bun install
npm run build:standalone
npm start          # приложение на http://localhost:3000
```
Для быстрой разработки вместо двух последних команд: `npm run dev`.

**Развернуть в интернете** — см. раздел 2.

## 2. Способ 1 (рекомендую): Vercel — 0 ₽

Почему Vercel: компания-создатель Next.js, бесплатный Hobby-план, HTTPS и домен
`*.vercel.app` выдаются сразу, деплой за ~2 минуты, 100 ГБ трафика в месяц —
для мини-аппа с запасом.

### Вариант А. Через GitHub (лучший — обновления автоматом)

1. Создайте репозиторий на **github.com** (кнопка New repository, имя например
   `vice-words`, Public).
2. В папке с проектом выполните:
```bash
git init
git add -A
git commit -m "VICE WORDS"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/vice-words.git
git push -u origin main
```
   (Git спросит логин/пароль — используйте Personal Access Token, GitHub
   покажет подсказку.)
3. Зайдите на **vercel.com** → Sign Up **Continue with GitHub**.
4. Add New… → Project → найдите репозиторий `vice-words` → **Import**.
5. Ничего не меняйте: Framework Preset определится сам (Next.js), команда
   сборки `next build` уже прописана в `package.json`, переменные окружения
   не нужны. Жмите **Deploy**.
6. Через пару минут — готовый адрес вида `https://vice-words-xxxx.vercel.app`.

Обновление приложения: изменили код → `git add -A && git commit -m "…" && git push`
→ Vercel пересоберёт сам.

### Вариант Б. Без GitHub — через Vercel CLI

```bash
npm install -g vercel
cd vice-words
vercel            # первый запуск: ответьте Enter на все вопросы
vercel --prod     # публикация в продакшн
```

### Вариант В. GitHub без консоли (мышкой)

github.com → New repository → ссылка «uploading an existing file» →
перетащите файлы из распакованного архива. GitHub принимает до 100 файлов за
один перетаскивание — грузите папками за несколько приёмов, затем Commit changes.
Дальше — как в варианте А с шага 3.

## 3. Альтернативные бесплатные хостинги

| Хостинг | Бесплатно | Нюансы |
|---|---|---|
| **Netlify** | да | Импорт из GitHub, Next.js поддерживается штатно. Хороший запасной вариант |
| **Render** | да | Засыпает после 15 минут простоя — первый визит после паузы грузится 30–60 сек |
| **Cloudflare Pages** | да | Нужен адаптер `@opennextjs/cloudflare`, больше ручной настройки |

GitHub Pages **не подойдёт** — он только для статики, а здесь работает
Next.js-сервер.

## 4. Подключить как Telegram Mini App

1. Разверните приложение по разделу 2 — Telegram требует HTTPS-адрес,
   на Vercel он есть сразу.
2. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username
   (должен заканчиваться на `bot`).
3. Той же командой `/newapp` (или Bot Settings → Menu Button):
   - выберите своего бота;
   - загрузите иконку **640×360** — она уже лежит в проекте:
     `public/icon-telegram.png`;
   - введите описание (например, «Выучи английский сленг GTA VI — прокачай
     свой ранг до Легенды Вайс-Сити»);
   - GIF можно пропустить (просто отправьте `/skip`);
   - вставьте адрес приложения: `https://vice-words-xxxx.vercel.app`;
   - введите название, которое увидят игроки: **VICE WORDS**.
4. Чтобы мини-апп открывался кнопкой в чате: `/setmenubutton` → ваш бот →
   вставьте тот же URL → подпись кнопки («ОТКРЫТЬ VICE WORDS»).

Готово — приложение живёт внутри Telegram, ссылка работает с любого устройства.

## 5. Частые вопросы

- **Прогресс на другом устройстве пропал?** Он хранится в localStorage, у каждого
  браузера свой. Если захотите облачную синхронизацию — бесплатно подойдут
  Turso или Supabase, но это отдельная доработка.
- **Свой домен?** Vercel → Settings → Domains → добавьте домен, сертификат
  выпустится автоматически.
- **Сколько это стоит?** 0 ₽ на Hobby-плане; платные лимиты вы никогда не
  встретите на трафике мини-аппа.
- **Иконка для BotFather не грузится?** Она должна быть именно 640×360 PNG —
  в проекте уже готовая: `public/icon-telegram.png`.
